# Write the festival's ordinary name; the checker finds its Wikipedia article.
# Lines starting with # are ignored, so you can park a festival rather than
# delete it. After the name, add any of these, separated by | :
#
#   2015-2026                      only these years
#   article: Exact Page Title      when the search picks the wrong page
#   setlistfm: city=Wacken         read from setlist.fm instead of Wikipedia,
#                                  for festivals whose article names only
#                                  the headliners. Two searches can be joined
#                                  with + when a venue has been renamed.
#   pattern: {year} Bonnaroo ...   when each year has its own article
#   matrix: yes                    when one table lists bands against years
#   cancelled: 2020,2021           editions that were announced but never
#                                  happened; the rows are kept and flagged,
#                                  never counted as appearances
#   per_day: 30                    how many different artists a real day of
#                                  this festival has — setlistfm only. Legend
#                                  Valley holds Lost Lands and two smaller
#                                  September festivals, and the big one is the
#                                  only one with thirty acts a day.
#   days: 3                        how many days in a row it runs — setlistfm
#                                  only. Werchter's field also hosts one-day
#                                  shows in the same weeks, and the length of
#                                  the run is what tells them apart.
#   months: 7,8                    which months the festival runs in —
#                                  setlistfm only, where it keeps other
#                                  events at the same place out. Riot Fest
#                                  and Summer Smash share a park and
#                                  nothing else tells them apart.
#

# many years have a real lineup and how many artists it can read, so you can
